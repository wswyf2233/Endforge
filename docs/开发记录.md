# 王剑模组 开发记录

## 环境

- Minecraft 1.20.1 / Fabric Loader 0.19.4 / Fabric API 0.92.11 / Yarn 1.20.1+build.1
- Java 17；无 Gradle Wrapper，用本机 Gradle 8.5
- 依赖：Accessories 1.0.0-beta.47（含 endec/gson/netty，需手动进 classpath）、GeckoLib 4.8.4（内含 mclib-20，同样要手动）、BetterCombat（软依赖，仅 weapon_attributes）

## 关键约定

- 所有物品贴图路径必须全小写，否则 `Identifier` 非法
- 盔甲层级贴图放 `assets/minecraft/textures/models/armor/`，材质 `getName()` 不带命名空间
- 语言文件键：`item.wangsword.<id>`，中文前缀 `§5`
- 配方放 `data/wangsword/recipes/`

## 发光方案

### 盔甲（ArmorGlowMixin）
- 注入 `ArmorFeatureRenderer.renderArmorParts` 的 TAIL
- 自建渲染层：`ENTITY_TRANSLUCENT_EMISSIVE_PROGRAM` + `LIGHTNING_TRANSPARENCY` + `DISABLE_LIGHTMAP` + `ALWAYS_DEPTH_TEST`
- 贴图：`ws_taiguarmor_layer_1/2_glowmask.png`
- 已知限制：`ALWAYS` 深度会导致隔着方块可见；改成 `LEQUAL` 会完全不显示（深度相等被剔除）

### 物品发光（现行实现：ItemGlowMixin + ItemGlowRegistry + ItemGlowRenderer）

要点（这两条是之前反复失败的根因）：

1. **绘制时机**：注入 `renderItem` 里对 `renderBakedItemModel` 的 INVOKE（`shift = AFTER`），
   此时矩阵**已经套好显示变换**，直接沿用即可；千万不要在 `renderItem` 的 TAIL 里自己再套一遍
   变换，那样手持姿势会整体错位（表现为"蓝色方块飘在旁边"）。
2. **UV 归一化**：原物品贴图在图集（atlas）里，UV 是图集坐标；发光遮罩是独立贴图，
   必须按 `quad.getSprite()` 的 min/max UV 归一化到 0~1，否则采样到的是遮罩上的错误区域。

流程：HEAD 里先 `getBuffer` 预申请发光层（保证它排在物品图层之后绘制）→ 原版画完模型后，
用同一份矩阵把模型的四边形用遮罩重画一遍（`MAX_LIGHT` + 自发光程序 + 加色 + LEQUAL + 开剔除）。

登记方式：`ItemGlowRegistry.register(物品, "item/xxx_glowmask")` 一行即可。

### 物品（旧方案，已废弃）
- 注入 `ItemRenderer.renderItem` 的 TAIL，用原版模型与显示变换重画一遍
- 用 `Map<Item, Identifier>` 维护"物品 → 发光贴图"：
  - 雷电宝石 → `ws_lightningstone.png`
  - 迅捷骑枪 → `ws_lance_2.png`
- 渲染层：`ENTITY_TRANSLUCENT_EMISSIVE_PROGRAM` + `LIGHTNING_TRANSPARENCY` + `DISABLE_LIGHTMAP` + `LEQUAL`
- Z 轴缩放 1.12（只沿法线外推，不改轮廓、避免亮边）
- 新增物品发光只需在 `GLOW_TEXTURES` 加一行

### 已否决的方案
- ETF / MoreMcmeta Emissive：都不处理盔甲层级贴图与普通物品
- 原版 `_e` 后缀：Complementary Reimagined 只支持方块和盔甲纹饰
- GeckoLib 用于武器：会丢原版模型 overrides（骑枪的拉弓模型切换）

## 已知坑

- Mixin 类内不能有非私有静态字段/方法 → 共享状态放 `client/GlowState`
- `RenderPhase.Texture`、`RenderLayer.MultiPhaseParameters` 是 protected → 已在 `wangsword.accesswidener` 放宽，并要在 `build.gradle` 的 `loom { accessWidenerPath }` 里指定
- 自建渲染层的 `Builder` 方法名是 `program(...)` 不是 `shader(...)`
- `RenderLayer.of` 参数是 `(name, VertexFormat, DrawMode, bufferSize, affectsOutline, translucent, params)`
- GeckoLib 物品需要 `GeoItem` 的三个方法：`registerControllers`、`getAnimatableCache`、`createRenderer`/`getRenderProvider`
- `RenderProvider.getCustomRenderer()` 返回的是 `BuiltinModelItemRenderer`，不是 `ItemRenderer`
- 光影（Complementary）不读 lightmap 做自发光，所以只能靠"另画一层 + 关光照"
